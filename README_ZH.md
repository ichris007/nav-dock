# Nav Dock

[English](./README.md) | [中文](./README_ZH.md)

> 将常用导航页、速查表和笔记放在 Obsidian Ribbon 旁边。鼠标悬停或点击图标，即可在浮层中查看内容，无需额外占用标签页。

Nav Dock 会在 Ribbon 图标旁打开一个 Markdown 文档浮层。浮层沿用 Obsidian 的 Markdown 预览样式，支持双链、嵌入、Callout、表格等常见内容，也可以直接在浮层中编辑文档。

## 功能亮点

- **随用随开的导航浮层**：将导航页、常用入口、速查表放在手边，不必切换标签页。
- **原生 Markdown 呈现**：沿用 Obsidian 的预览样式，字体、行高、标题、引用块、Callout、表格、嵌入内容和 Dataview 渲染结果与正文保持一致。
- **悬停或点击打开**：悬停模式适合快速查看；点击模式更稳妥，不容易误触。两种模式可以随时切换。
- **多种打开方式**：通过 Ribbon 图标、命令面板、快捷键或 `obsidian://` URI 打开。
- **智能处理链接**：优先激活工作区中已打开的文档，避免重复打开标签页；按住 `Ctrl` / `Cmd` 点击可强制新开。
- **双链悬停预览**：在浮层中悬停 `[[双链]]`，即可查看页面预览，无需按住 `Cmd`。
- **直接编辑**：点击正文即可进入编辑状态，修改后自动保存；按 `Esc` 退出编辑。
- **尺寸可调**：拖动浮层右下角即可调整宽高，尺寸会保存并在下次打开时沿用。
- **快速查找导航文档**：在设置中输入文字，即可按文件名和目录筛选笔记。
- **内置图标选择器**：搜索并选择 1500+ 图标，支持滚动加载。
- **中英双语界面**：支持跟随系统、中文和英文，切换后命令、提示和设置项同步更新。
- **文档内锚点导航**：点击 `#标题` 只在浮层内部滚动，不会跳转到其他页面或关闭浮层。
- **适配不同工作区**：支持明暗主题、左右侧栏的固定与悬浮形态，并会在窗口尺寸变化后重新定位。

## 安装

1. 前往 [GitHub Releases](https://github.com/ichris007/nav-dock/releases) 下载最新版压缩包。
2. 解压后，将 `main.js`、`manifest.json` 和 `styles.css` 放入库目录下的 `.obsidian/plugins/nav-dock/`。
3. 重启 Obsidian，进入 **设置 → 第三方插件**，刷新插件列表并启用 **Nav Dock**。

**运行要求：** Obsidian 1.5.0 或更高版本；仅支持桌面端。

## 快速开始

1. 启用 Nav Dock 后，左侧 Ribbon 会出现一个图标，默认使用指南针图标。
2. 打开 **设置 → Nav Dock**。
3. 在「导航文档」中输入要显示的笔记名称或路径，也可以点击「用当前笔记」选择当前打开的文档。
4. 将鼠标移到 Ribbon 图标上，即可查看导航文档。

例如，你可以创建一篇 `Homepage.md`，把项目入口、常用笔记和速查资料整理在里面，再将它设为 Nav Dock 的导航文档。

## 使用说明

### 打开与收起

| 打开方式 | 如何打开 | 如何收起 |
| --- | --- | --- |
| **悬停打开**（默认） | 鼠标移到 Ribbon 图标上 | 鼠标移出图标和浮层约 220 ms 后自动收起 |
| **点击打开** | 点击 Ribbon 图标 | 再次点击图标、按 `Esc`，或点击浮层外部 |

补充说明：

- 鼠标移入浮层后，浮层会保持打开，方便阅读和点击链接。
- 图标与浮层之间留有 8 px 间距；悬停模式带有约 220 ms 的收起延迟，鼠标经过间隙时不容易误关。
- 通过 Ribbon 图标打开时，浮层贴近 Ribbon 显示。
- 通过命令、快捷键或 URI 打开时，浮层会在屏幕中央显示，并带有遮罩；点击遮罩可关闭浮层。
- 拖动浮层右下角可以调整宽高。若手动拖动高度，可能会覆盖原有的自适应高度设置；可在设置中恢复自适应。

### 命令与快捷键

按 `Cmd/Ctrl + P` 打开命令面板，搜索「Nav Dock」。

| 命令 | 行为 |
| --- | --- |
| **Nav Dock：打开/关闭导航浮层（固定，不随鼠标离开收起）** | 在屏幕中央打开并固定浮层；鼠标移开不会自动收起。再次执行命令可关闭浮层。 |
| **Nav Dock：在标签页打开导航文档** | 将导航文档作为普通标签页打开；如果该文档已经打开，则直接切换到它。 |

你也可以在 **设置 → 快捷键** 中搜索 `Nav Dock`，为命令绑定快捷键。

### URI 调用

Nav Dock 提供以下 URI：

```text
obsidian://nav-dock?action=toggle
obsidian://nav-dock?action=open-in-tab
```

可以将 URI 放在笔记中作为链接，也可以通过 Meta Bind 或按钮类插件调用。

| 参数 | 行为 |
| --- | --- |
| `action=toggle` | 打开或关闭导航浮层；省略 `action` 时默认执行此操作。 |
| `action=open-in-tab` | 在标签页中打开导航文档。 |

### 设置项参考

| 设置项 | 说明 |
| --- | --- |
| **界面语言** | 跟随系统、中文或英文；切换后设置项、命令和提示同步更新。 |
| **导航文档** | 指定要在浮层中显示的笔记。输入文字可筛选文件，也可以使用「用当前笔记」。 |
| **打开方式** | 在悬停打开与点击打开之间切换；浮层标题栏中的按钮也可以切换，且与设置同步。 |
| **图标** | 打开图标选择器进行搜索和选择；支持滚动加载，并会高亮当前图标。 |
| **提示文字** | 设置鼠标悬停在 Ribbon 图标上时显示的提示。 |
| **浮层宽度** | 可设置为 280–720 px，并与拖拽调整同步。 |
| **高度自适应上限** | 以视口高度百分比设置浮层的自适应高度上限；超出后在浮层内部滚动。 |
| **恢复自适应 / 重置尺寸** | 恢复自适应高度，或将宽高都重置为默认值。 |
| **显示标题栏** | 在浮层顶部显示文件名和「在标签页打开」按钮。 |
| **双链打开位置** | 选择在新标签页或当前标签页打开；按住 `Ctrl` / `Cmd` 点击始终新开。 |
| **点击链接后收起** | 默认开启。点击普通链接后浮层收起；文档内锚点（如 `#标题`）不会触发收起。 |
| **编辑文档** | 无需单独开关：点击正文即可进入编辑，按 `Esc` 退出并自动保存。 |

## 如何编写导航文档

导航文档就是普通的 Markdown 笔记。你可以按自己的工作流组织入口，例如：

```markdown
# 导航

## 工作台
- [[项目总览]]
- [[本周周报]]
- [[待办清单]]

## 知识库
- [[读书笔记]]
- [[Templates/日记模板|日记模板]]

> [!tip] 提示
> 浮层里点击链接会跳转，并按设置自动收起。
```

Callout、表格、任务列表、`![[嵌入]]` 和 Dataview 渲染结果等内容也可以正常显示。

## 自定义浮层外观

如果想单独调整 Nav Dock 浮层的背景、边框、圆角或阴影，可以在 Obsidian 的 CSS 片段中覆盖以下 CSS 变量，无需修改插件文件：

```css
body {
  --nav-dock-bg: var(--background-primary);
  --nav-dock-border: var(--background-modifier-border);
  --nav-dock-radius: var(--radius-l);
  --nav-dock-shadow: var(--shadow-l);
}
```

## 常见问题

### 浮层打开后是空白的？

请先前往 **设置 → Nav Dock**，检查是否已经设置「导航文档」。输入框支持模糊筛选；可以填写相对路径（例如 `Homepage`）或完整路径。

### 点击浮层里的链接没有反应？

Nav Dock 会在捕获阶段处理浮层中的内部链接点击。由于浮层挂载在 `document.body` 下，Obsidian 1.14.4 的相关事件委托可能无法正常接收到点击。如果你遇到链接异常，请在 [GitHub Issues](https://github.com/ichris007/nav-dock/issues) 提交反馈。

### 如何关闭双链悬停预览？

进入 **设置 → 页面预览**（核心插件），关闭「Nav Dock 浮层」对应的选项。

### 分屏时，新标签页打开到了错误的窗格？

这是目前已知的限制。在多窗格布局下，新标签页可能会打开在非激活窗格。插件会尽力定位当前激活窗格，但 Obsidian 没有公开 API 可以可靠地获取该信息。如遇到此问题，欢迎在 [GitHub Issues](https://github.com/ichris007/nav-dock/issues) 反馈。

### Nav Dock 支持移动端吗？

暂不支持。Nav Dock 仅面向桌面端（`isDesktopOnly`）。
